# 15차: 운영 결함 수정 — 알림 형식·요약 유실, 예약 실행 독립 경로, 지인 공유 마무리, 실제 행사 원문 대조

작성 2026-10-22. 모두 운영(main)에 반영·배포했다. 소유자 전용 모드는 유지했다.

## 1. 알림 형식·요약 유실(최우선)
| 문제 | 수정 |
|---|---|
| 원문 주소가 본문 절반, 한 통에 여러 건 + 번호 버튼 나열 | 행사당 한 통. 제목 굵게, 날짜는 "10월 27일(화)", 비어 있는 항목은 줄째 생략, 주소는 "🔗 바로가기" 글자에 숨김 |
| 요약이 너무 많음 | 봇마다 하루 주요 5건만 한 건씩(2주 안 접수 시작·마감 → 1주 안 행사 우선). 나머지는 버튼 없는 제목 목록 한 통(제목을 누르면 원문) |
| 요약 4,000자 자르기로 뒷부분 행사가 잘렸는데 발송 완료로 기록(독립 검증 지적) | 글자 수 기준으로 나눠 각 통에 실제로 들어간 행사만 그 통의 결과로 기록. 실패한 통의 행사만 다음 실행에서 재발송 |
| 텔레그램이 서식을 거부할 때 | 태그를 뺀 일반 글로 재발송 |

시험: 긴 행사 30건 → 모든 통 4,096자 이하·30건 모두 발송, 23건 → 5건 개별 + 18건 목록, 한 통 실패 → 그 통 행사만 재발송.

## 2. 예약 실행 신뢰성
- 실제 기록: 운영 첫날 GitHub 예약 작업이 4.5시간 늦음(00:05 → 04:31). 04:40 수집은 아직 한 번도 제때 돌지 않음.
- **독립 경로**: Worker 안의 Durable Object 알람이 매시 35분 스스로 깨어남. 할 일은 세 가지다.
  - 발송(즉시·⏰ 접수 시작·마감)
  - 일간 요약
  - 수집 지연 감시
- **운영 확인**: 2026-10-22 07:35:00 UTC 알람이 GitHub 없이 실행됐다.
- **한국 시스템 영향 없음**: Cloudflare 예약 실행(cron) 슬롯은 쓰지 않는다. 한국 Worker 가 5개를 모두 쓰고 있어서다.
- **수집 지연 복구**
  - 지연 기준: 가벼운 실행 6시간, 전체 26시간 넘게 기록이 없으면 지연으로 본다.
  - 비밀값 `GH_DISPATCH_TOKEN` 이 있으면 GitHub 에 수집 실행을 직접 요청한다.
  - 토큰이 없으면 소유자에게 하루 한 번 알린다.
- **지연 기록**: 수집 실행마다 예약 시각 대비 실제 시작 지연(분)을 남긴다.

## 3. 지인 공유
- **거리 판정(`/city`)**
  - `/city Westminster 40` 이면 콜로라도 도시 좌표 기준 40마일 밖의 일반 행사는 보내지 않는다.
  - 국립·주립공원 허가, 추첨, 예약, 시간지정 입장, 연례·드문 행사는 거리와 상관없이 보낸다.
  - 행사 위치를 모르면 거르지 않는다.
- **구독 해지·재개**
  - `/stop`: 그 봇 수신을 중단하고, 남은 대기열은 건너뛴다. 소유자에게 알린다.
  - `/start`: 본인이 중단했던 승인된 지인은 다시 승인받지 않고 바로 재개한다.
- **신규 가입자**
  - 승인·재개 때 쌓인 행사 수백 건은 보내지 않는다.
  - 2주 안 접수 시작·마감만 최대 15건을 첫 요약으로 보낸다.
  - 그보다 먼 접수일은 그날 ⏰ 알림으로 간다.
- **시나리오 시험(지인 발송을 켠 로컬 환경)**
  - 가입 → 승인 → 첫 요약 4건(먼 행사 40건 제외)
  - 거리 판정: 먼 일반 2건 제외, 허가·연례·위치 모름은 발송
  - 버튼 기록 → `/stop` 뒤 발송 0 → `/start` 재개 후 정상 수신

  - 원문을 받을 수 있었던 22건 중 **날짜·시간 불일치 0건**이다.
  - 원문에 있는데 비어 있던 값: 비용 2, 시간 2, 종료일 1, 접수 상태 1.

  - 원문을 못 받은 18건(대학 경기 일정 14, Apex PRD 4)은 대조하지 못했다. 피드 자체의 날짜·시간을 쓴다.

  - 측정용 미등록 기관 10곳 중 AI 발굴로 찾은 곳은 0~1곳이다.
  - 등록 정보원 밖의 행사 발견은 아직 약하다.

## 6. 지인 공유 시작 판단
**아직 이르다.** 아래 세 가지가 끝나면 시작해도 된다고 본다.
1. **수집 자동 복구 토큰**: `GH_DISPATCH_TOKEN` 을 등록하고, 2~3일간 예약·독립 경로로 수집·발송이 제때 도는 것을 확인한다.
2. **월 AI 상한**: 상한을 올리지 않으면 이달 말 AI 분석이 멈춘다.
3. **새 알림 형식 확인**: 소유자가 새 알림 형식을 하루 이상 받아 보고 확인한다.
