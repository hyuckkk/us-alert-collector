# A·B 실행 결과 — 개인정보 이력 정리 · 전체 검색 성능 시험

결론: **A 는 공개 저장소 기준 완료(남은 일 2가지), B 는 결과가 나빠 운영 배포(C·D)로 넘어가지 않는다.**

## 1. A — 개인정보 이력 정리

| 단계 | 결과 |
|---|---|
| 백업 | 작업 직전 원격 6개 브랜치 전체를 비공개 번들로 백업(검증 통과). 소유자에게 비공개 전달 |
| 최신 브랜치 리허설·검증 | 재작성 전 23건 → 후 0건, `main` 변경 없음, 브랜치별 커밋 수 동일(stage4-preop 70) |
| 강제 push | stage1-review, stage2-fixes, stage3-fixes, stage4-preop — 변경 전 커밋을 확인하는 방식(lease)으로 성공 |
| `stage1-structure` | 삭제는 이 세션의 GitHub 연결에서 **거부(403)** → 대신 정리된 이력으로 덮어씀(내용은 깨끗). **소유자가 GitHub 화면에서 삭제 필요** |
| 공개 저장소 새 클론 검사 | 모든 브랜치·모든 커밋 **0건**, 현재 파일 0건(알려진 노출 문구 7개 기준) |
| `main` | 변경 없음(커밋 동일) |
| 옛 커밋 직접 접근 | **아직 가능**: 웹 74/74, API 5/5, git fetch 5/5(표본) — GitHub 지원 요청 필요 |

남은 노출과 할 일:
1. **옛 커밋 74개가 커밋 번호로는 아직 열린다.** GitHub 지원 요청(요청문·목록 비공개 전달) → 처리 후 `scripts/check_old_commits.sh` 로 0 확인.
2. `stage1-structure` 브랜치 삭제(소유자, Branches 화면 휴지통).
3. `PRIVACY_TERMS` 입력(소유자) → CI 엄격 검사로 소유자 검사어 기준 재확인.

**사고 보고:** 강제 push 를 GitHub 이 "모든 파일 변경"으로 처리해, 경로 조건이 걸린 워크플로가 승인 없이 실행됐다.
- `staging-test` 1회: 시험 Worker·D1 생성 후 삭제 확인, 운영 자원 변화 없음, D1 쓰기 9,421행(계정 하루 42.4%).
- `collect` 건식 1회: Worker·텔레그램 쓰기 없음, **AI $1.26 사용**.
- 재발 방지: 경로 조건 워크플로 4개(staging-test, experiments, collect, probe-sources)는 이제 강제 push 에서 실행하지 않는다.
- 다른 브랜치에서는 실행이 없어 실패 메일도 없었다.

## 2. B — 전체 검색 성능 시험(1회)

- 실행: https://github.com/hyuckkk/us-alert-collector/actions/runs/39549077703 — 29분, **AI 실사용 $2.47**(상한 $4.70, 호출 117회, 웹 검색 17회).
- 오늘 AI 합계: $3.73(B $2.47 + 위 사고 $1.26). 상한 계산은 응답의 토큰 수 × 설정 단가 기준이며, 청구액은 Anthropic 콘솔에서 확인이 필요하다.
- 처리 규모: 수집 1,134건(등록 정보원 645, 키워드 검색 478, AI 발굴 11), AI 추출 1,134건 전부, 최종 행사 159건(관련 없음 740, 판정 제거 57, 중복 180, 지난 행사 1).

## 3. 판단

조건 4("결과가 나쁘거나 핵심 접수정보 오류 → 운영 배포로 넘어가지 않음")에 해당한다. **C(병합·배포)·D(운영)는 진행하지 않는다.**

운영 전 꼭 고쳐야 할 것(추가 기능이 아니라 결함 수정, 승인 대상):
1. **상세 본문 위치**: 제목이 마지막으로 나오는 곳부터 자르기(기준 목록 수집 스크립트에서 이미 효과 확인한 방식).
2. **RSS·목록 항목 상세 조회**: 본문이 짧으면 상세 페이지를 열어 비용·연령·신청 조건을 확보.
3. **접수 안내 페이지**: 접수 시작일이 있는 안내는 행사가 아니어도 '접수 시작' 알림 대상으로 남기도록 추출 지시 보완.
4. **날짜 없는 행사**: 날짜를 못 뽑으면 바로 알리지 않고 보류(지난 행사 오발송 방지).
5. **중복 판정**: 날짜가 다른 같은 이름 행사(무료입장일 등)를 합치지 않기.
6. **AI 발굴**: 등록 외 정보원 발견 0 — 지난 일정만 가져오는 지시를 "앞으로 60일 일정"으로 고치고, 독립 표본 지역(인근 시 공식 일정)을 정보원 후보로 등록.

수정 후 같은 시험 1회 재실행(상한 약 $3)으로 확인한 뒤 C·D 판단을 권한다.
