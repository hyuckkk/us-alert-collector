# Claude 독립 검색 지시서 (매일 예약 실행이 읽는 파일)

Claude 예약 검색은 매일 한 번 이 파일을 읽고 그대로 따른다. GitHub 수집기·ChatGPT 검색과는 **독립적으로** 콜로라도 행사를 찾는다. 세 경로가 서로 놓친 것을 찾아 메우는 것이 목적이다.

## 1. 먼저 읽을 것
1. `external-inbox/LESSONS.md`
   - 지난 누락 교훈이다. 거기 적힌 **검색어와 감시할 공식 페이지는 반드시 이번 검색에 넣는다.**
2. `docs/ISSUE-21-22-24.md`
   - 추천 기준이다. "평소 정상가로 언제든 살 수 있는 상품·일정인가?"를 먼저 묻는다.

## 2. 무엇을 찾나 (적극 알림 후보만)
- **가족 단위**: 덴버 광역권(Westminster 거점) 가족(성인 2 + 어린이 3), 2026년과 2027년 6월~2028년 8월 체류.
- **찾을 것**
  - 평소 닫힌 시설 개방: 군·공군·우주군 기지, 공항, 연구소, 무대 뒤
  - 공공기관·학교·대학이 지원해 무료이거나 크게 싼 특별 프로그램
  - 수량 한정 무료 입장일: 박물관·동물원·식물원 SCFD free day
  - 국립·주립공원 허가·추첨·시간지정 예약
  - 1년에 한 번 이하의 드문 행사, 시즌 한정 체험
  - 학교·지역 공동체의 비정기 행사: 지역 토너먼트, 운동회, 학생 축제
- **관심 분야(이슈 #41·#42·#43)**: 군사(미국판 job5: 기지 개방·에어쇼·군용기·헬기·전차 전시·탑승), 대규모 공개 사격·공식 사격 대회, 3D 양궁, 유소년 사냥·낚시 대회, 가족 래프팅·카약, 태권도 대회, BMX·MTB, 체조 대회, 로데오, 열기구 실탑승, 몬스터트럭, NASCAR, 서킷의 합법 드래그·야간 튜닝카 행사(일상 봇)
- **분야별 확인 사항**(원문 문장으로)
  - 군사시설: 외국 국적자(한국 여권)도 들어갈 수 있는지. 'open to the public'만으로는 '미확인'이다. 미확인 행사는 확인될 때까지 보류된다.
  - 사격: 사격장이 1년 내내 파는 체험·대여 패키지는 보내지 않는다. 대회 참가비와 총기·탄약·보호구·관람 비용을 나눠 적는다.
  - 카약·래프팅: 아빠와 아이 3명이 같은 날 같이 탈 수 있는지 확인한다. 계절·수위별 최소 나이, 최소 체중, 급류 등급, 가족 총비용을 적는다. 다른 업체의 기준을 가져다 쓰지 않는다.
- **찾지 않을 것**(받아도 걸러진다)
  - 정가 일반 공연(Red Rocks 정기 공연, 오케스트라 정기 공연), 프로 경기
  - 초·중·고·대학 정기 경기(따로 달력 페이지가 있다)
  - 요가·명상·사운드배스·공예·쿠킹 같은 일반 유료 수업
  - 영어 강연·대담·세미나·다큐 상영, 회의·행정
  - 매주 반복되는 프로그램의 한 회차
- **지역 범위**
  - 생활권은 덴버 광역권이다.
  - 콜로라도 전역은 정말 드문 체험만 찾는다.
  - 검색 범위는 넓게 잡는다: 시·카운티·학교구·대학·공공기관 공식 사이트, 공원 레크리에이션 지구, 박물관 공식 일정.

## 3. 어떻게 보내나
- **파일 경로**: `external-inbox/claude/<UTC 시각>-daily.json` 하나에 모은다. 예: `20261024T1300Z-daily.json`. 30건까지.
- **형식**: 스키마 `us-alert-inbox/1`(`collector/external_ingest.py` 맨 위 설명).
  - 각 행사에 아래를 채운다.
    - `url`: 기관 공식 페이지
    - `verified`: 공식 페이지를 직접 열어 확인했는지
    - `found_at`, `origin: "scheduled"`
    - `recommend`
    - `special_reason`: 한국어 한 문장
    - 날짜(`start_date`, `registration_opens`, `deadline`)
  - 날짜를 모르면 비운다. 지어내지 않는다.
- **작업량(`run`)**
  - 시작·끝 시각, 실제 검색어 목록, 검색 횟수, 연 URL 수·성공 수, 공식 페이지 확인 수, 후보 수, 제외 수와 사유를 적는다.
  - 모르는 값은 빼면 된다.
- **올리기**: `claude/search-<날짜>` 브랜치로 push 한다. push 되면 `external-inbox` 워크플로가 자동으로 처리한다.
  - 처리 순서: 공식 페이지 재확인 → 추천 판정 → 같은 행사 판별 → 소유자·승인된 지인에게 한 통씩.
- **중복**
  - 이미 알린 행사를 다시 보내도 된다. 같은 행사로 판별해 다시 알리지 않는다.
  - 다른 경로가 이미 찾았는지도 시스템이 대조해 기록한다.
- **금지**
  - 키·토큰을 파일에 넣지 않는다.
  - 텔레그램에 직접 보내지 않는다.
  - 한국 알림 시스템은 건드리지 않는다.
