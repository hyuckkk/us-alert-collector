# 외부 검색 입력함

ChatGPT·Claude 의 예약 검색은 찾은 행사를 이 폴더에 **새 파일**로 만든다. 새 파일이 push 되면 `external-inbox` 워크플로가 자동으로 처리한다.

- 경로
  - ChatGPT: `external-inbox/chatgpt/<고유이름>.json`
  - Claude: `external-inbox/claude/<고유이름>.json`
  - 고유이름은 영문·숫자·`.`·`_`·`-` 만 쓴다. 예: `2026-10-23T1200Z-run1`.
- 처리하는 파일
  - 새로 만든 파일만 처리한다. 고친 파일과 지운 파일은 무시한다.
  - 같은 파일을 같은 내용으로 다시 올려도 한 번만 처리한다.
- 제한
  - 파일 하나는 200KB 이하, 행사는 30건 이하다.
  - push 한 번에 파일 10개까지 받는다.
- 처리 방식
  - 공식 페이지를 다시 읽어 확인한다. 확인하지 못한 행사는 보내지 않는다.
  - 그다음 추출 → 판정 → 추천(특별 근거 필수) → 같은 행사 판별을 거친다.
  - 미국 봇 3개로 소유자에게만 보낸다. 행사 하나에 메시지 하나이고, 출처 표시는 없다.
- 형식: `collector/external_ingest.py` 맨 위 설명(스키마 `us-alert-inbox/1`)을 따른다.
  - 모르는 작업량 값은 빼면 된다. 빠진 값은 `unknown` 으로 기록한다.
- 비밀값: 파일에 키·토큰을 넣지 않는다. Worker 관리 키는 GitHub Secrets 에만 있다.
